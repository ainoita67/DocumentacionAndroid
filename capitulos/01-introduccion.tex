\chapter{Introducción}
En este documento se describe la aplicación Android que hemos desarrollado en Kotlin.
La aplicación reúne varias funcionalidades independientes a las que se accede desde un menú inicial: una calculadora, un conversor de divisas, una lista de recetas y un menú con tres juegos.

Los juegos son piedra, papel o tijera, un lanzador de dados y luces fuera.

Cada capítulo explica una funcionalidad, con una captura de la pantalla y las clases y funciones que hemos creado para ella.
En los casos más importantes se incluye también el fragmento de código.

Todas las pantallas comparten la misma paleta de colores para que la aplicación tenga un aspecto uniforme.

Al final del documento se incluye la información de uso de IA.
